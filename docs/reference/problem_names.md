# Problem names

Extract the names of the problems in an object.

## Usage

``` r
problem_names(x, ...)
```

## Arguments

- x:

  [`multi_problem()`](https://prioritizr.net/reference/multi_problem.md)
  object.

- ...:

  not used.

## Value

A `character` vector of names.
