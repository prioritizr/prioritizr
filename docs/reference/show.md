# Show

Display information about an object.

## Usage

``` r
# S4 method for class 'ConservationModifier'
show(x)

# S4 method for class 'ConservationProblem'
show(x)

# S4 method for class 'OptimizationProblem'
show(x)

# S4 method for class 'Solver'
show(x)
```

## Arguments

- x:

  Any object.

## Value

None.
